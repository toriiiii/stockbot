# Frontend

StockBot utlizes React Native for the frontend

## Prerequisites
- JavaScript

## Expo Setup

1. Clone this repo 
```
git clone https://github.com/toriiiii/stockbot.git
```

2. Go into the stockbot-frontend folder
```
cd stockbot/frontend/stockbot-frontend
```

3. Verify that npm and node are installed or install from https://nodejs.org/en
```
node -v
npm -v
```

4. Install Expo CLI
```
npm install -g expo-cli
```

5. Start expo
```
npx expo start -c
```

6. Scan the QR code with a phone that has the 'Go Expo' app.
